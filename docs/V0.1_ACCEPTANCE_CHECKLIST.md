# V0.1 Acceptance Checklist

This checklist is derived from the canonical IntentGuard v2.2 implementation order and release gates.

## Foundation
- [x] Java 21 + Spring Boot modular-monolith base
- [x] MySQL 8.x + Flyway
- [x] Task/session/activity persistence model
- [x] Health/readiness endpoints
- [x] Next.js/React/Tailwind dashboard shell

## Deterministic simulator
- [x] Task creation
- [x] Session creation bound to task
- [x] Simulator activity request
- [x] Deterministic policy evaluation
- [x] Activity persistence
- [x] Dashboard activity display

## Policy invariants
- [x] Unknown/unregistered tool -> DENY
- [x] Out-of-scope resource -> DENY
- [x] Expired task -> DENY
- [x] Inactive task -> DENY
- [x] Forbidden action -> DENY
- [x] In-scope tool/resource -> ALLOW

## Verification
- [x] Backend CI has MySQL service
- [x] Frontend CI build
- [x] Backend policy unit tests
- [ ] Fresh CI run after final V0.1 changes
- [ ] Final V0.1 PR review/merge

## Explicitly deferred to V0.2
- MCP gateway forwarding
- Protected downstream MCP tool
- Tool/server registration
- Tool manifest enforcement
- DENY-before-execution proof
- Direct downstream bypass test

Do not mark V0.1 complete until the fresh CI run and PR review are green.
